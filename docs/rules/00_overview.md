# ヘキサうどん 競技ルール概要

2026-09-21に公式公開版の募集要項・フォーマット・Q&A・行動詳細を再照合した作業用仕様。
本選固有の制約は[本選条件](../competition/finals-conditions.md)、HTTPは[通信仕様](../competition/protocol.md)を参照。
出典の略号と確認範囲は [資料一覧](../sources/08_sources_and_open_questions.md) を参照。
基本規則は募集要項G、具体的な処理と訂正はQ&A・補足資料を併読する。

## 目的と構成

巡回車でスポットを巡り、補給車で燃料を補いながらうどんを獲得する。
募集要項G p.12では、試合全体の種類数、各日に獲得した種類数の合計、玉数総和、
回答時間累計の順に比較する。詳細と未確認点は [勝敗判定](05_scoring.md)。

- 六角形グリッド。0始まりの偶数行が右にずれ、端の折り返しはない（Q1・Q2）。
- 1チーム3～8体（Q50）。試合前に種別を指定する（F p.3）。
- 巡回車は `kind=0`、補給車は `kind=1`（F p.2）。
- 各日の全車両の行動をまとめて提出する。
- 1試合4～10日、マップは縦横それぞれ8～32セル（G p.8）。

## 実装で重要なルール

- 移動時間・燃料量は移動元の地形で決まる（Q10・Q11・Q25）。
- 燃料消費と位置変更は移動完了ステップに行う（S p.4）。
- 移動完了までは元のセルに滞在し、獲得・補給・交通量更新の対象になる。
- 処理順は燃料消費、移動反映、うどん獲得、補給、交通量更新（Q6）。
- ステップ0は行動予約のみ。最終ステップも獲得・補給・交通量更新を行う。
- 各車両の行動時間の合計をその日の規定ステップ数に厳密に一致させる。
- 1台でも不正な計画なら回答全体がリジェクトされる（F p.3、Q6）。
- 「最大積載量」は燃料の上限。うどんの積載上限ではない（F p.1、Q14・Q51）。
- 入力の `day` は初日が0。実際の第 `day+1` 日の計画を作る（F p.2）。
