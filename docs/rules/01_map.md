# マップ

出典の略号は [資料一覧](../sources/08_sources_and_open_questions.md) を参照。

## 座標と隣接

縦幅をH、横幅をW、左上を `(x,y)=(0,0)` とする。
セルIDは `pos=y*W+x`、範囲は `0..H*W-1`（G p.8、図1）。
縦横それぞれ8～32セル（G p.8）。

本選の区分別条件は[本選の盤面条件](../competition/finals-conditions.md)を参照。
2026-09-18公式資料では1回戦・敗者復活戦16×16、準決勝24×24、決勝戦32×32（公式PDF原本と照合済み）。

0始まりの偶数行が右にずれる六角形配置で固定される（Q1）。
端を越えた折り返しはない（Q2）。
次の座標差はQ1の配置とQ47の方向から導いたもの。

|方向値|方向|偶数行の (dx,dy)|奇数行の (dx,dy)|
|---|---|---|---|
|0|左上|(0,-1)|(-1,-1)|
|1|右上|(1,-1)|(0,-1)|
|2|右|(1,0)|(1,0)|
|3|右下|(1,1)|(0,1)|
|4|左下|(0,1)|(-1,1)|
|5|左|(-1,0)|(-1,0)|

例：W=8なら、セル0の右下はセル9、左下はセル8。
セル8の右上はセル0、左上はマップ外。

## 地形とコスト

地形コードはF p.1、コスト表はG p.9の表1。
各セルの地形タイプは試合中に変化しない。道路状態は同一日中には変化しない（G p.9）。

|地形コード|地形|移動可否|移動ステップ数|巡回車の燃料消費|
|---|---|---|---|---|
|0|平地|可|2|1|
|1|道路・順調|可|1|2|
|1|道路・混雑|可|2|2|
|1|道路・渋滞|可|4|2|
|2|山地|可|3|2|
|3|池|不可|-|-|

移動時間も燃料量も移動元セルを参照する（Q10・Q11・Q25）。
待機時間は地形に依存せず、燃料消費はない（Q16・Q49）。

## 配置の保証

- 全エージェントから全ての平地・山地・道路に到達可能（Q46）。地形の連結性の保証であり、現在の燃料だけで到達できる保証ではない。
- 各地形が少なくとも1セル存在する（Q35）。
- 地形が占める割合に追加の上限・下限はない（Q58）。
- 1セル内のスポットは最大1つ（Q18・Q34）。
- スポットは平地にある（S p.4、巡回車Eの説明）。
