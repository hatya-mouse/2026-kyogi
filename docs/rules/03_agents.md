# エージェント・移動・燃料

出典の略号は [資料一覧](../sources/08_sources_and_open_questions.md) を参照。

## 車両と初期設定

1チーム3～8体（Q50）。初期位置は車両ごとに異なり、全チームで共通（Q37・Q38）。
初期位置はスポットのない平地（G p.10）。種別は試合終了まで変更できない（G p.10）。

|kind|種別|役割|移動時の燃料|
|---|---|---|---|
|0|巡回車|スポットでうどんを獲得|移動元の地形に応じて消費|
|1|補給車|巡回車へ燃料を供給|消費しない|

kindの対応はF p.2。補給車は無限に燃料を供給し、移動で燃料を消費しない（G p.11）。
巡回車は燃料を供給できず、補給車はうどんを獲得できない（G p.10）。
補給車にも入力 `fuel` があるが、有限の巡回車用燃料制約を適用する根拠にはならない。

試合前に各車両の種別を回答する。有効な回答がなければ全車が巡回車になる（Q53、F p.3）。

## 燃料積載量

`fuelLimits` は全巡回車に共通する燃料上限F（F p.1、Q51）。
正の整数で、初日のステップ数Nに対し `N <= F <= 3*N`（Q14・Q31・Q60・Q62）。
Nの整数倍に限定されない。必要移動燃料より上限が小さいことはない（Q36）。

これはうどんの積載上限ではない。うどんの獲得玉数に上限はない（G p.9）。
燃料上限は全チームの全巡回車に共通（G p.11）。

初日は満タン（G p.11）。
翌日は前日の残燃料を引き継ぎ、入力の `fuel` で通知される（Q19）。

## 移動・待機

隣接6方向への移動と、指定ステップ数の待機を組み合わせる。
同じセルに複数車両が存在できる（Sの例）。移動先が池またはマップ外なら不正。

移動時間と燃料量は移動元セルで決まる（Q10・Q11・Q25）。
移動を予約し、必要ステップ数が経過した反映フェーズで燃料を消費して位置を変更する。
完了前は元のセルにいる（S p.4）。
G p.11の燃料不足時の命令禁止とSの移動待ち中の補給例には食い違いがあり、
この文書では後の具体例Sに合わせている。詳しくは [資料内の不整合](../sources/08_sources_and_open_questions.md)。

待機は地形によらず指定したステップ数で、燃料を消費しない（Q16・Q49）。
行動中に命令を割り込ませることはできない（Q23）。
各日の行動計画全体を事前に提出する。詳細は [ステップ処理](07_step_processing.md)。

## 補給

反映フェーズの補給処理時に、補給車と巡回車が同じセルにいることが条件（Q22）。
燃料は自動的に最大積載量まで回復する（G p.11）。

- 同じステップで同じセルに到着した場合も、その反映フェーズで補給される。
- 最終ステップに合流しても補給される。
- 一方の到着と同時に他方が別セルへ移動完了した場合、補給されない。
- 移動完了待ちで出発セルにいる間も、同じセルなら補給対象。
- 消費は補給より前なので、その移動完了時の燃料不足を同じ反映フェーズの補給で解消することはできない。
- 補給後の燃料は後続の移動に使える。行動予約との対応はQ6・Q22およびSを併読する。
- 補給車と同じ経路・タイミングで移動する巡回車は、各反映フェーズ終了時に満タンとなる（Q48）。

ステップ0は補給されない。到着後さらに待機1ステップが必須という意味ではない。
補給は自チームの補給車からのみ受けられる。他チームの補給車と同じセルにいても補給されない
（2026-09-05、ユーザーによる確認）。
