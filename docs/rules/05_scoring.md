# 勝敗判定

出典：G p.12「勝敗判定」、Q32・Q56。
出典の略号は [資料一覧](../sources/08_sources_and_open_questions.md) を参照。

## 比較の優先順

1. 試合全体で獲得したうどんの種類数が多い。
2. 各日に獲得したうどんの種類数の合計が多い。
3. 試合全体の獲得玉数が多い。
4. 各日の最後の有効回答までの回答時間の合計が短い。
5. サイコロなどで勝敗を決めるか、引き分けとする。

各優先項目が同点の場合だけ次の項目を比較する。
種類はスポットの系列に対応する。同じ種類の玉数を増やしても種類数は増えない。

## 種類数の集計

日dに獲得した系列の集合をB[d]、試合日数をDとすると、

- 第1基準：全日の和集合 `|B[1] ∪ ... ∪ B[D]|`。
- 第2基準：当日の集合サイズの合計 `Σ |B[d]|`。

第2基準は「各日終了時点の試合累積種類数の合計」ではない。
同じ日に複数の車両が同じ系列を獲得しても、その日の種類数には1回だけ数える。
別の日に同じ系列を再び獲得すると、第2基準にはその日も1種類として加算する。

例：4日間で当日の獲得系列が `{A,B}, {B}, {C}, {A,C}` の場合、
試合全体は3種類、日別合計は `2+1+1+2=6`。
各日までの累積種類数 `2+2+3+3=10` は得点には使わない。

## 回答時間

各日の最後の有効回答が送られるまでに要した時間を合計する（G p.12、Q56）。
最初の有効回答までの時間でも、ソルバのCPU実行時間でもない。
回答時間の最小単位は秒（Q32）。

有効回答後に改善案を送り直すと、最後の有効回答までの時間が順位判定に影響する。
種別決定の時間をこの累計へ加えるとは記載されていない。
有効回答なしの日の算入方法、秒未満の丸め方は提供資料では未確認。
