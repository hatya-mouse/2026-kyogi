# ステップ処理と具体例

出典：Q6～Q8・Q16・Q22～Q27・Q48・Q49、S pp.1～4。
出典一覧は [資料一覧](../sources/08_sources_and_open_questions.md) を参照。
Sの表と本文の不整合は同一覧に記録している。以下は本文のフェーズ順を基準にした整理。

## 1日の時間軸

1日Nステップを時点0～Nで表す。0は開始時点で、N+1回行動できる意味ではない。

|時点|反映フェーズ|アクションフェーズ|
|---|---|---|
|0|なし|最初の行動を予約|
|1～N-1|下記の順に状態を更新|行動が完了した車両は次の行動を予約|
|N|下記の順に状態を更新|なし|

行動を時点tで予約し、所要時間がkなら完了時点はt+k。
完了待ちの間は、別の行動を予約できない。
行動列を事前に提出するので、各時点でサーバーに新たな命令を送る方式ではない。

## 反映フェーズの順序

各処理を全車両に対して終えてから次へ進む。
車両1の移動・獲得・補給を全て終えてから車両2へ進む方式では、
同時に出入りする場合の判定を誤る。

1. この時点で移動が完了する巡回車の燃料を、移動元地形の必要量だけ減らす。
2. 完了する移動の位置を全て反映する。未完了なら出発セルにとどまる。
3. 現在地がスポットの巡回車に獲得処理を行う。競合時は配列添字の昇順。
4. 同じセルにいる同一チームの補給車・巡回車について補給する（チーム条件は2026-09-05のユーザー確認）。
5. 更新後の位置で交通量を数える。

次にアクションフェーズで、空いた車両に行動列の次の行動を予約する。
燃料不足などの不正は受付時の事前検証で回答全体を拒否する（Q6）。

移動予約時に燃料を実際に引いたり、その時点の残量だけで拒否すると、
Sの巡回車Aの補給例を再現できない。この文書は後の具体例Sに合わせ、
計画内の補給を含めて検証し、燃料消費時点で必要量があるというモデルを採る。
ただしG p.11の燃料不足時の命令禁止とは文言が食い違うため、
[資料内の不整合](../sources/08_sources_and_open_questions.md) にサーバーでの確認事項を残している。

## 例1：平地のスポットから出発

時点0で、平地スポットにいる巡回車が右移動を予約する。
平地の移動は2ステップかかる。

|時点|位置と処理|
|---|---|
|0|元のスポットで予約。獲得・補給なし|
|1|まだ元のスポット。在庫と当日未獲得条件を満たせば1玉獲得|
|2|燃料1を消費し、右隣へ到着。そのセルで獲得・補給・交通量判定|

日初にスポット上にいる場合、出発前の待機を明示しなくても
時点1では出発セルに残るので獲得できる（Sの巡回車E）。

## 例2：移動待ち中の補給

Sの巡回車Aは、時点1で混雑道路セル1に到着し、燃料は1。
同時点のアクションフェーズで、セル2への移動を時点3完了として予約する。
時点2に補給車がセル1へ来ると、移動待ち中のAも燃料3まで補給される。
時点3には道路の燃料2を消費し、残燃料1でセル2へ到着する。

この公式例から、予約時の残燃料だけで移動不可と判断してはいけないことが分かる。
移動完了より前の補給は利用できる。一方、移動完了と同じ反映フェーズでの補給は
消費より後なので、その移動の燃料不足を救済できない。

## 例3：すれ違いと最終ステップ

巡回車がセルcに到着する反映フェーズで、補給車がcから別セルへ移動完了するなら、
補給処理時には別セルなので補給されない。
補給車の移動がまだ完了していなければcにいるので補給対象になる。

最終時点Nに同じセルへ到着した場合にも補給される（Q22）。
到着後に追加の1ステップ待機は必要ない。

## 例4：同時獲得と終了待機

Sでは時点4にBとGが在庫1のスポットへ到着し、配列順が早いBだけが獲得する。
時点5に来るCは在庫切れで獲得できない。

移動を終えた時点がNより小さい場合、残り時間を待機で埋める。
Nにちょうど到着するなら追加待機は不要。Nを越える移動は不可。

## 実装時の確認ケース

- 時点0ではうどんも補給も交通量も増えない。
- 移動未完了の車両にも毎ステップ獲得・補給・交通量判定を行う。
- 燃料消費は移動完了時のみで、待機完了では消費しない。
- 全車両の位置を更新してから、合流・すれ違いを判定する。
- 同時獲得は車両の配列順、最終ステップでも獲得・補給する。
- 規定ステップ数の不足と超過の両方を拒否する。
